oddzen

Custom Linux kernel for AMD Zen+/Polaris hardware on Debian. Built from mainline 7.1.5 with the Zen patchset, compiled with Clang 21 + LLD.

Install Features Tuning Build Links

Install

One command. Debian 13 (Trixie), amd64.

$ curl -s 'https://raw.githubusercontent.com/cpntodd/oddzen/master/install-oddzen.sh' | sudo bash

Adds the oddzen apt repo, installs the kernel + headers, and updates GRUB.

Manual Install

# Add the GPG key
sudo mkdir -p /etc/apt/keyrings
curl -fsSL https://cpntodd.github.io/oddzen/oddzen-archive-keyring.gpg | \
    sudo gpg --dearmor -o /etc/apt/keyrings/oddzen-archive-keyring.gpg

# Add the apt source
echo 'deb [arch=amd64 signed-by=/etc/apt/keyrings/oddzen-archive-keyring.gpg] https://cpntodd.github.io/oddzen/repo stable main' | \
    sudo tee /etc/apt/sources.list.d/oddzen.list

# Install
sudo apt update
sudo apt install 'linux-image-*-oddzen' 'linux-headers-*-oddzen'
sudo reboot

Features

Zen Patchset

The Zen kernel applies scheduling, memory reclaim, and I/O patches that bias toward lower latency. Under mixed desktop load, interactive tasks get CPU time sooner than with Debian's stock config.

AMD Zen+ / Polaris

Configured for Ryzen 5 2600 (Family 17h) and Radeon RX 570/580. Full amdgpu with Southern Islands, Sea Islands, and Display Core for HDMI/DP audio.

Clang 21 + LLD

Compiled with LLVM/Clang 21.1.8 instead of GCC. No particular advantage — I wanted to confirm the LLVM build path works on 7.x, and it does. bindeb-pkg with LLVM=1 is straightforward.

What's Enabled

  • Filesystems: Btrfs, XFS, NTFS3, exFAT, CIFS/SMB, OverlayFS
  • NFS client & server
  • WireGuard, bridge, VXLAN
  • KVM + VIRTIO, NVMe built-in
  • Realtek r8169 built-in (not a module)

Performance Tuning

Setting Value
CPU Scheduler EEVDF — Earliest Eligible Virtual Deadline First
Preemption PREEMPT_DYNAMIC — lazy preemption for desktop
Timer tick 1000 Hz — low-jitter scheduling
I/O Scheduler mq-deadline — multiqueue-aware
TCP Congestion CUBIC
RCU Preemptible tree-based hierarchical RCU

These are the Zen-kernel tunables that differ from Debian's stock config. The Zen patchset also adjusts watermark boost factor, hugepage reclaim, and CPUFreq governor thresholds — all in the direction of lower scheduling latency under mixed desktop workloads.
